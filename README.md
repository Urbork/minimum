# minimum

Początek nowego projektu strony internetowej.

Na żywo: https://urbork.github.io/minimum/

## Sterowanie

- ruch kursorem — rysuje biały ślad, który powoli zanika
- przytrzymanie `Q` — wstrzymuje rysowanie śladu
- `Esc` lub przycisk „wyczyść ślad" — czyści cały ślad

## Uruchomienie

Otwórz `index.html` w przeglądarce albo uruchom lokalny serwer:

```bash
python -m http.server 8000
```

Następnie wejdź na http://localhost:8000
